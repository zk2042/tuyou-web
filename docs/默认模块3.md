# 前台/前台活动模块

## POST 创建活动

POST /activities

仅领队（role=0）可创建。

【必填】title            — 活动标题，最大50字
【必填】category         — 活动分类：徒步/露营/骑行/登山/跑步/攀岩/溯溪
【必填】coverImg         — 封面图URL（仅1张）
【必填】address          — 活动举办地点
【必填】startTime        — 开始时间 "YYYY-MM-DD HH:mm"，必须晚于当前时间 + 48小时
【必填】endTime          — 结束时间
【必填】price            — 费用，0=免费，必须为正数
【必填】maxPeople        — 人数上限
【必填】difficulty        — 难度：入门/中等/中高等/高等
【必填】activityContent  — 活动介绍，最长2000字

signUpStart/signUpEnd 由后端自动计算（signUpStart=创建时间，signUpEnd=开始时间-48h），前端无需传入。

> Body 请求参数

```json
{
  "title": "楠溪江溯溪一日",
  "category": "溯溪",
  "coverImg": "https://example.com/cover.jpg",
  "address": "浙江温州·楠溪江",
  "startTime": "2026-08-15 09:00",
  "endTime": "2026-08-15 17:00",
  "price": 0,
  "maxPeople": 15,
  "difficulty": "中等",
  "activityContent": "溯溪一日体验线..."
}
```

## POST 报名/取消报名

POST /activities/{id}/signup

切换式接口：已报名则取消，未报名则报名。

报名校验：
- 活动不存在/已删除 → 404
- 活动已满员 → 2001
- 不在报名时间内（signUpStart ~ signUpEnd） → 2001
- 活动已结束 → 2001

返回 {isJoined: bool, currentPeople: int}

# 前台/前台的笔记模块

## POST 发布笔记

POST /notes

【必填】title    — 标题，最长50字
【必填】content  — 正文，最长2000字
【必填】category — 分类：1徒步 2露营 3骑行 4登山 5跑步 6攀岩 7溯溪
【必填】tags      标签，1~3个，必须是已启用的标签
【必填】images    图片URL，1~5张，第一张为封面
【可选】videoUrl — 视频地址，最长255；非空时images必须恰好1张

> Body 请求参数

```json
{
  "title": "周末骑行千岛湖环线",
  "content": "千岛湖环线太美了，全程150km",
  "category": 3,
  "tags": ["徒步", "骑行"],
  "images": ["https://cdn.example.com/img1.jpg"],
  "videoUrl": ""
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 否 |none|
|» title|body|string| 是 |none|
|» content|body|string| 是 |none|
|» category|body|integer| 是 |none|
|» tags|body|[string]| 是 |none|
|» images|body|[string]| 是 |none|
|» videoUrl|body|string| 是 |none|

> 返回示例

> 200 Response

```json
{
```
