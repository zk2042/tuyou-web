# 2026-08-18 后台敏感词管理 · 搜索接口 —— 接口说明 + 前端配合（独立档）

> 本文件仅包含**敏感词搜索接口**。API 定义见同目录 `2026-08-18-敏感词管理-openapi3.json`（可直接导入 Apifox，tag `后台/敏感词管理`）。

---

## 一、接口说明（1 个，需管理员登录）

### `GET /admin/sensitive-words` —— 分页查询敏感词（**含搜索**）

| 参数 | 位置 | 必填 | 说明 |
|---|---|---|---|
| `page` | query | 是 | 页码，从 1 开始 |
| `size` | query | 是 | 每页条数（≤100） |
| `keyword` | query | 否 | 按词内容 `LIKE %keyword%` 模糊搜索；空 = 不筛选 |

返回 `data`：
```json
{
  "list": [
    { "id": "1", "word": "代开发票", "status": 1, "create_time": "2026-08-01 10:00:00" },
    { "id": "2", "word": "高价回收", "status": 1, "create_time": "2026-08-01 10:00:00" }
  ],
  "total": 1127,
  "page": 1,
  "size": 10,
  "total_page": 113
}
```
- `status`：`1`=启用，`0`=停用
- 错误码：401 未登录/令牌无效；400 参数校验失败；500 服务器内部错误

---

## 二、前端配合点

1. **管理后台加"敏感词管理"菜单**：列表页用 `GET /admin/sensitive-words`（`page`/`size`/`keyword`），搜索框输入 `keyword` 调接口即可。
2. **只读搜索**：本接口仅提供分页搜索查询；敏感词的增删不通过本接口（另行处理）。
