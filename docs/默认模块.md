## POST 发表评论

POST /comments

对指定笔记（targetType=1）或攻略（targetType=2）发表评论或回复他人评论。
【必填】targetType — 目标类型：1=笔记，2=攻略；非 1/2 返回 2001
【必填】targetId   — 目标笔记/攻略 ID，目标不存在返回 404
【必填】content    — 评论内容，最长 300 字
【可选】replyToId  — 被回复的一级评论 ID；空 = 一级评论，非空 = 二级评论（回复）
【可选】replyToMemberId — 被回复的用户 ID；回复一级评论时可省略（默认取该一级评论作者），回复二级评论时必传（用于展示 @用户名）

【变更】命中敏感词不再拒绝（原 2001 "内容包含违规词汇"拦截移除）：内容存原文、命中词落库 is_sensitive=1 / hit_words，响应 content 为打星后文本。

错误码：401 未登录/令牌无效；400 参数校验失败（content 为空/超长、参数类型错误）；404 目标笔记/攻略不存在；500 服务器内部错误。
返回的评论对象带 canDelete（本人刚发布的评论恒为 true），前端可直接用。

> Body 请求参数

```json
{
    "targetType": 1,
    "targetId": 9,
    "content": "镇上租车很方便",
    "replyToId": 1
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 否 |none|
|» targetType|body|integer| 是 |none|
|» targetId|body|integer| 是 |none|
|» content|body|string| 是 |none|
|» replyToId|body|integer| 否 |none|
|» replyToMemberId|body|integer| 否 |none|

> 返回示例

> 200 Response

    "message": "成功",

            "id": "1",

        "replyToId": "1",
        "replyToNickname": "跑步酱",

    }
}

## GET 获取二级评论列表（加载更多）

GET /comments/replies/{id}

分页获取指定一级评论（:id）下的二级回复，用于一级评论「展开」时加载更多。
【必填】page — 页码，从 1 开始
【必填】size — 每页条数，默认 10，最大 100

排序规则：前 2 条按热度排序，其余按发布时间倒序。列表项为评论对象（无嵌套 replies）。

【变更】content 为敏感词打星后文本；user.nickname 亦为打星后。

错误码：401 未登录/令牌无效；400 id 格式不正确（参数错误: id格式不正确）；404 一级评论不存在；500 服务器内部错误。
列表项带 canDelete：当前登录用户是评论作者或作品作者时为 true。

|id|path|string| 是 |一级评论 ID|
|page|query|integer| 是 |页码，从 1 开始|
|size|query|integer| 是 |每页条数，最大 100|

> 200 Response

{

## DELETE 删除评论

DELETE /comments/{id}

评论者本人或作品作者可删除，采用软删除（delete_time 置位，列表查询天然过滤）。删除一级评论时，其下所有二级评论一并删除；删除二级评论仅删除自身。前端无需在此接口上判断权限——评论对象已带 canDelete 字段，canDelete=true 时才渲染删除按钮，否则不渲染。后台管理员删除请走后台评论删除接口。status 字段保留给笔记生命周期管理（后台笔记下架/恢复的批量状态同步会自动跳过已软删评论）。
错误码：401 未登录/令牌无效（请提供认证令牌）；400 id 格式不正确（参数错误: id格式不正确）；403 无权删除该评论（非本人或非作品作者）；404 评论不存在；500 服务器内部错误。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |评论 ID|

> 返回示例

> 200 Response

```json
{
    "code": 0,
    "message": "成功",
    "data": {}
}
```
