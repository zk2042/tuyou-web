# 前台/登录注册

## POST 注册接口

POST /auth/register

> Body 请求参数

```json
{
    "phone": "19561986897",
    "code": "169854",
    "nickname": "猫",
    "password": "123456",
    "confirmPassword": "123456"
}
```

|» password|body|string| 是 |none|

## POST 验证码发送接口

POST /auth/send-code

> Body 请求参数

```json
{
    "phone": "18300707586",
    "scene": "login"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» phone|body|string| 是 |none|
|» scene|body|string| 是 |login(登录)、register(注册)、reset-pwd(重置密码)|

> 返回示例

> 200 Response

```json
{
    "code": 0,
    "message": "成功",
    "data": {
        "message": "验证码已发送"
    }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|object|true|none||none|
|»» message|string|true|none||none|
