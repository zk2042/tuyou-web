## POST 注销账号

POST /auth/cancel

注销当前登录账号（需密码 + 短信验证码双重校验，验证码完全复用登录/注册的 sms 机制，场景 cancel-account）。
【必填】phone — 当前账号绑定的手机号（发码时用同一个手机号，scene=cancel-account）
【必填】code — 手机验证码
【必填】password — 原密码

校验顺序即错误分支：手机号格式 → 手机号≠当前账号绑定手机号（"手机号与当前账号不符"，防止拿别人手机号的码注销自己）→ 验证码错误/过期 → 密码错误。
成功后：账号置 status=2（已注销）、登录态 token 被清除；内容全部保留不删除。前端需清登录态并跳登录页，提示"账号已注销"。

错误码：401 未登录/令牌无效；400 手机号格式不正确 / 手机号与当前账号不符 / 验证码错误或已过期 / 密码错误；404 账号不存在；500 服务器内部错误。

> Body 请求参数

```json
{
    "phone": "15000000001",
    "code": "881608",
    "password": "123456"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» phone|body|string| 是 |当前账号绑定手机号|
|» code|body|string| 是 |手机验证码（scene=cancel-account）|
|» password|body|string| 是 |原密码|

> 返回示例

> 200 Response

```json
{
    "code": 0,
    "message": "成功",
    "data": {
        "message": "注销成功"
    }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|object|true|none||none|

## GET 用户详情（他人公开资料卡）

GET /personal/member/{id}

查看任意用户公开资料卡（登录即可）。用于关注列表、粉丝列表、评论区、活动报名人等所有带头像处点击头像跳转。

字段说明：
- nickname / bio 已做敏感词打星后返回（不含原文）；
- status：0=禁用，1=正常，2=已注销（已注销用户仍返回资料卡，前端标注"已注销"）；
- role：领队 / 普通会员；
- isFollowed：我是否关注了 TA；isFollower：TA 是否关注我（用于互关判断）；
- leadingCount：带队次数（普通会员为 0）；
- 不返回 phone、password。

错误码：401 未登录/令牌无效；404 用户不存在；500 服务器内部错误。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |目标用户 ID|
