## 开发任务：途友·个人主页（静态页面）

### 一、页面概述

完成「途友」App 的个人主页（`src/pages/Profile/index.tsx`），展示用户个人信息、社交数据、内容分类入口。**本次为纯静态页面**，无需对接接口，使用 静态 数据填充展示。


### 二、页面结构（自上而下）

```

───────────────────────────
│                             │
│┌──────────┐  山林旅人        │← 用户昵称（大号，加粗）    (左侧头像，靠近头像右侧是上面昵称，下面个性签名，
││  👤 头像 │                 │  ← 用户头像（圆形，大尺寸）右侧是一支笔写横线的图标，点击图标是编辑页)
│└──────────┘ 热爱徒步，每周一山│← 个人签名（小号，灰色）
│                         │
│   23    156    328       │  ← 社交数据（横向排列）都是白色字体，数据粗，文字细，数据字体颜色要比文字字体颜色亮
│   内容   关注   粉丝     │（以上均是在背景图片上显示，背景图片有自下而上的由黑色到灰色到浅的渐变效果）背景图片下边两个角有圆角
│                         │（点击内容是笔记和攻略的划片选择列表，点击关注是关注列表，点击粉丝是粉丝列表）
│  ┌───────────────────┐  │
│  │ 我的内容           │  │  ← 功能入口（网格布局）
│  │ 我的收藏           │  │我的内容里是用户发布的笔记和攻略列表
│  │ 我的点赞           │  │我的内容里是用户点赞的笔记和攻略列表
│  │ 我的活动           │  │
│  │ 设置              │  │
│  └───────────────────┘  │
├─────────────────────────┤
│  社区  活动  消息  我的   │  ← 底部TabBar（"我的"高亮）
└─────────────────────────┘
```


### 三、各区域详细拆解

#### 3.2 用户信息区

**布局**：居中排列

| 元素 | 内容               | 样式说明                                         |
| ---- | ------------------ | ------------------------------------------------ |
| 头像 | 用户头像图片       | 大尺寸圆形（如 120px），使用 Avatar 组件或自定义 |
| 昵称 | 山林旅人           | 字号较大（如 36px），加粗                        |
| 签名 | 热爱徒步，每周一山 | 字号较小（如 24px），灰色（#999）                |
| 编辑 | 编辑图标 | assets/iconfont.css里的.icon-bianji图标                |
**静态 数据**：
```javascript
const userInfo = {
  avatar: 'https://picsum.photos/200?random=1',
  nickname: '山林旅人',
  signature: '热爱徒步，每周一山'
}
```

#### 3.3 社交数据区

**布局**：横向三等分排列

| 数据 | 数值 | 标签 | 说明                 |
| ---- | ---- | ---- | -------------------- |
| 内容 | 23   | 内容 | 用户发布的笔记和攻略数量   |点击进入Content页面
| 关注 | 156  | 关注 | 用户关注的其他人数量 |点击进入FollowList页面 |
| 粉丝 | 328  | 粉丝 | 关注用户的人数       |点击进入FollowerList页面 |

**样式**：
- 三个数据块横向均匀分布，数据在上，标签在下
- 数值：大号、加粗、深色（如 32px）
- 标签：小号、灰色（如 24px）

**静态 数据**：
```javascript
const socialStats = {
  notes: 23,
  following: 156,
  followers: 328
}
```

#### 3.4 功能入口区

**布局**： ，每个宫格一个入口，每个宫格包含图标 + 文字+向右箭头，点击某行实现跳转

| 入口     | 图标            | 文字     | 点击行为（占位）         |
| -------- | --------------- | -------- | ------------------------ |
| 我的内容 | assets/iconfont.css里的.icon-neirong图标 | 我的内容 | 点击进入Content页面 |
| 我的收藏 | assets/iconfont.css里的.icon-shoucang图标 | 我的收藏 | 点击进入Favorite页面 |
| 我的点赞 | assets/iconfont.css里的.icon-like图标 | 我的点赞 | 点击进入Like页面 |
| 我的活动 | assets/iconfont.css里的.icon-activity图标 | 我的活动 | 点击进入Activity页面 |
| 设置     | assets/iconfont.css里的.icon-bianji图标 | 设置     | 点击进入Settings页面 |

**样式**：
- 每个入口竖直居中对齐
- 图标尺寸适中（如 48px）
- 图标右边显示文字（如 26px）
- 卡片背景白色，上边两个带有带圆角，图标和文字在左侧，箭头在右侧

### 九、开发顺序建议

```
1. Profile 页面文件（index.tsx + index.less）
2. 实现用户信息区（头像 + 昵称 + 签名+编辑）
3. 实现社交数据区（横向三等分）
4. 实现功能入口区
5. 使用 静态 数据填充
6.点击编辑图标，进入编辑资料页（和发布笔记和活动页面的编辑资料页布局相同）：
头部用HeaderNavBar组件，有取消文字，参考发布笔记和活动页面，教编辑资料，固定到头部，点击取消文字返回个人中心。
下面是编辑头像模块，左上角有“文字”，字体参考发布笔记和活动页面的“添加图片”字体样式，正中间是Avatar组件，点击后弹出头像选择器。
下面是背景图模块，参考发布笔记和活动页面的“添加图片”模块，仅将文字改成“背景图”，一张图片就可以了，点击后弹出背景图选择器。
下面是类似发布笔记和活动页面的输入表单模块，有“昵称”显示字数x/y右下角最大为20字和“签名”显示字数x/y右下角最大为100字。前者是输入框，后者是文本域。
下面是”保持“按钮，参考发布笔记和活动页面的“保持”按钮，同步到个人中心。
以上就是编辑资料页的所有功能，进入编辑资料页后，头像和背景图都是先显示当前用户正在使用的，昵称和签名也是默认显示当前用户的昵称和签名。
7.点击内容数据，跳转到Content页面：
内容页面就是用户发布的笔记和攻略，头部是HeaderNavBar组件，无取消文字，固定头部，下面是查看笔记和攻略划片选择器，激活颜色为#428a46，刚进入时，默认显示笔记列表，在下面的列表是渲染参考首页的那个瀑布列表，布局是一样的，点击攻略列表，跳转到攻略列表，点击进入详情页和首页列表进入详情页有区别的是，头部右上角有三个点，点击底部就有删除按钮。
8.点击关注数据，跳转到FollowList页面，头部是HeaderNavBar组件，无取消文字，固定头部，下面是关注列表，每个关注项左侧是用户头像，靠近头像的右边是用户上面昵称下面是用户签名，右侧是关注按钮，白色关注文字，#428a46色背景，点击关注按钮，切换关注状态为灰色背景，文字变灰色，文字的灰色要深一点，文字居中细，点击头部左箭头返回个人中心。
9.点击粉丝数据，跳转到FollowerList页面，和关注页一样，头部是HeaderNavBar组件，无取消文字，固定头部，下面是粉丝列表，每个粉丝项左侧是用户头像，靠近头像的右边是用户上面昵称下面是用户签名，右侧是关注按钮，白色关注文字，#428a46色背景，点击关注按钮，切换关注状态为灰色背景，文字变灰色，文字的灰色要深一点，文字居中细，点击头部左箭头返回个人中心。
10.点击我的内容，跳转到Content页面。
11.点击我的收藏，跳转到Favorite页面，头部是HeaderNavBar组件，无取消文字，固定头部，参考内容页面的布局，就是用户收藏的笔记和攻略，就是将like图标换成收藏图标，均是填充背景颜色的图标，assets/iconfont.css里的.icon-shoucangfill图标,如果用户点击收藏图标，图标会切换为取消收藏图标assets/iconfont.css里的.icon-shoucang图标，点击除了图标其他区域，会进入到笔记或者攻略的详情页。
12.点击我的点赞，跳转到Like页面，头部是HeaderNavBar组件，无取消文字，固定头部，参考内容页面的布局，就是用户点赞的笔记和攻略，就是将like图标换成点赞图标，均是填充背景颜色的图标，assets/iconfont.css里的.icon-likefill图标,如果用户点击点赞图标，图标会切换为取消点赞图标assets/iconfont.css里的.icon-like图标，点击除了图标其他区域，会进入到笔记或者攻略的详情页。
13.点击我的活动，跳转到Activity页面，头部是HeaderNavBar组件，无取消文字，固定头部，参考内容页面的布局，就是用户发布的活动和参与的活动，点击会展示对应的活动列表，参考活动页面的布局，就是用户发布的活动和参与的活动，点击会展示对应的活动详情。
14.点击设置，跳转到Settings页面，头部是HeaderNavBar组件，无取消文字，固定头部，点击取消文字返回个人中心，头部以下会有空隙分开不同模块，有开关模块，有进入入口模块，均采用个人中心功能模块的布局，在开关模块里有消息通知，位置服务，将右侧的箭头改成开关按钮，在进入入口模块里有编辑资料（和个人中心的编辑不一样，待开发），隐私设置，帮助与反馈，关于途友，还是向右的箭头，模块没有圆角，模块之间有空隙，每个模块是白色背景，模块之后是退出按钮，忘记密码按钮，注销账号按钮，点击任意选项，显示待开发，点击退出，就提示用户确认退出，类似发布笔记和活动弹出框那样。
9. 配置路由
```


### 十、注意事项

1. **本次为纯静态页面**：不需要对接接口，所有数据使用局部静态数据
2. **头像使用 picsum.photos** 或项目内占位图
3. **功能入口图标**：可使用 Emoji 或项目内 SVG/字体图标
4. **点击交互**：点击未开发的功能入口，显示 Toast 提示，不跳转实际页面
5. **头像颜色**：可参考设计稿使用渐变背景（如橙色渐变）
